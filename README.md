# Agentic Possible

Minimal landing page for a Detroit-based software and automation consultancy.

## Run locally

No build step is required. Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Update the contact email in `index.html`.
- Edit copy directly in `index.html`.
- Design tokens and responsive styles live in `styles.css`.

## Deploy

This is a static site and can be deployed to GitHub Pages, Netlify, Cloudflare Pages, Vercel, or any static host.
